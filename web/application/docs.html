Documentation

Supported paths, evaluation contracts, and production boundaries.

Import

Sign in with an invitation, open Agents, and import a pinned public GitHub repository or ZIP. A private repository may require a scoped read token. Source ZIPs are limited to 4 MiB compressed, 12 MiB expanded, and 1,500 files.

Configure evaluation

Choose the actual application entry point, command arguments containing {prompt}, and three to six test cases covering train, validation, and holdout. Expected stdout must come from independent application behavior. Test expectations remain outside source imports.

{"module":"src.qa","args":["{prompt}"],"cases":[{"name":"first","split":"train","prompt":"...","stdout":"..."},{"name":"second","split":"validation","prompt":"...","stdout":"..."},{"name":"third","split":"holdout","prompt":"...","stdout":"..."}]}

Execution and export

The selected DeepSeek and GLM models run through the Vultr broker. Each case is executed in a bounded disposable gVisor sandbox. Runs have request budgets and share a global concurrency ceiling. Verify behavior from the run detail screen; only a passing fresh original-runtime check enables export.

Current supported scope

The live verified path is Python 3.11 and non-streaming OpenAI-compatible Chat Completions. A pinned Node 22 / Vercel AI SDK 7 sandbox passed transport preflight, but an independent paid TypeScript migration has not yet passed. Arbitrary frameworks, production databases, streaming, and unrestricted external tools are not supported.

For reproduction steps and underlying receipts, see the engineering runbook.
