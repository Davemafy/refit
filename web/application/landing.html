Open Refit workspace →How it works

Create an account to run a migration. The workspace includes a recorded example you can explore without signing in.

01Import the original application

Inspect a pinned GitHub revision or source ZIP. Refit reports the entry point and runtime boundary before execution.

02Compare real execution

Run original cases with source and replacement models inside disposable gVisor containers. Examine case and tool evidence.

03Verify before exporting

Export model configuration only after the original application passes fresh verification. Failed migrations keep their evidence, not a fake success.

Current compatibility

Verified Python 3.11 non-streaming OpenAI-compatible applications. A curated Node / AI SDK runtime is in testing; successful live TypeScript migration is not yet established.
