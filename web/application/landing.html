THE PLATFORM

Don’t rewrite the agent.
Find out what broke.

Model switching changes more than the answer. It can change tool calls, decision paths and application state. Refit examines the behavior that matters, not just the text the model returns.

ISOLATION

Your agent runs.
Your host stays separate.

Refit's trusted controller runs on Vultr Cloud Compute. Original agent code executes in disposable gVisor workers. Model requests are brokered through Vultr Serverless Inference, outside the worker.
